# CV Web — Sebastián Campos

CV personal de una sola página, construido con HTML, CSS y JavaScript puro (sin frameworks ni build tools).

## Ver el sitio

Es un sitio 100% estático: alcanza con abrir [index.html](index.html) en el navegador, o servirlo con cualquier servidor estático (por ejemplo `npx serve` o la extensión Live Server de VS Code).

## Estructura

```
index.html          Contenido de todas las secciones (Inicio, Sobre mí, Experiencia,
                     Estudios, Habilidades, Certificados, Proyectos, Contacto)
css/estilos.css      Estilos, variables de color, layout y responsive
js/app.js            Carrusel de certificados, menú móvil, animaciones al
                     hacer scroll, sección activa del menú y botón "volver arriba"
img/                 Imágenes (logo, foto de perfil, certificados, experiencias, proyectos)
documentos/          CV en PDF descargable
```

## Contenido

Presenta mi perfil: formación (Tecnicatura Universitaria en Programación —
UTN Haedo — y cursos de Coderhouse), experiencia laboral, habilidades técnicas, certificados
obtenidos y proyectos personales.
